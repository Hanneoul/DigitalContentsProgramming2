# FinalExam01 요구사항

## 이번 작업: 빌드 오류 복구
- FinalExam01 프로젝트만 수정한다. 기존 학생 AI와 게임 규칙, 다른 프로젝트의 변경사항은 유지한다.
- 실제 Visual Studio 2026 / MSVC 빌드 오류를 재현하고 프로젝트 설정 누락을 수정한다.
- 표준 C 함수 사용을 유지하면서 C4996 오류를 해소하고 UTF-8 소스를 올바르게 컴파일한다.
- C17/C 컴파일을 명시하고 순위 저장 모듈 ranking.c를 빌드에 포함한다.
- 실행 파일 옆 dungeonmap.dat 배포와 프로젝트 내부 출력/중간 디렉터리를 설정한다.
- Debug/Release 및 x64/Win32 빌드와 기존 self-test, 짧은 자동 실행으로 검증한다.
- 변경사항은 Build.txt에, 오류 원인과 검증 결과는 작성 시각과 함께 BuildLog.txt에 이어 쓴다.

## 이번 작업: 이름/상태 UI, 열쇠 자동 복귀, 신규 맵
- 각 playerN.c에 학생이 편집할 수 있는 playerN_name 문자열을 추가한다. 기존 AI 전략은 유지한다.
- 성향(Evader/Attacker 등) 대신 이름을 표시한다. 한글/영문 이름을 고정 표시 폭으로 정렬한다.
- HP는 두 칸 블록으로, 리스폰은 13칸 배경색 게이지와 정확한 남은 턴 숫자로 표시한다.
- 휴식 게이지는 사망 시 가득 차고 남은 휴식 비율에 따라 줄어든다. 휴식 종료 후 시작점 점유 대기는 별도로 표시한다.
- 열쇠 미소유가 연속 30턴이면 최초 자리로 복귀한다. 획득 시 초기화하며 버리기/사망/탈출로 바닥에 새로 놓인 턴은 세지 않는다.
- 화면 맨 아래에 열쇠 소유 상태와 복귀까지 남은 턴을 표시한다. AI 상태 파일에도 호환 가능한 추가 정보로 제공한다.
- 맵과 순위표를 함께 표시할 폭이 부족하면 순위표를 아래로 옮긴다. 탭 환경에 의존하지 않는 고정 셀 폭으로 정렬한다.
- 기존 13x13에서 한 변 약 30% 증가한 17x17 맵으로 교체한다. 바깥 이동은 넓게, 문 근처에는 짧은 구조물과 복수 진입로를 배치한다.
- 신규 로직/표시/맵 검증을 추가하고 기존 AI 행동 테스트 실패는 별도로 보고한다.
